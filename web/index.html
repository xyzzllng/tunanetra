HOW IT WORKS

Dari tombol ke informasi.

Alur ini mengikuti pembagian tugas pada firmware dan backend saat ini.

7 LANGKAH
  1. 01⏻

    Sistem dinyalakan

    ESP32 dan ESP32-CAM memperoleh daya lalu mencoba bergabung ke jaringan Wi-Fi.

  2. 02⌁

    ESP32 inisialisasi

    Firmware menyiapkan tombol, HC-SR04, buzzer, speaker I2S, dan koneksi WebSocket.

  3. 03◎

    Sensor mengukur jarak

    HC-SR04 membaca jarak. Peringatan halangan dekat berbunyi lokal; sampel jaringan dikirim pada kondisi firmware tertentu.

  4. 04◉

    Tombol memilih fungsi

    Pengguna menekan salah satu dari tiga tombol untuk meminta mode objek, ekspresi, atau rambu.

  5. 05▣

    Kamera mengambil gambar

    Backend meminta satu atau beberapa gambar dari ESP32-CAM ketika deteksi diperlukan.

  6. 06✳

    Backend memproses data

    Model AI di komputer backend menganalisis gambar; kamera dan ESP32 tidak menjalankan model tersebut.

  7. 07♫

    Informasi disampaikan

    Ringkasan suara dikirim kembali ke ESP32 untuk diputar melalui speaker I2S.
